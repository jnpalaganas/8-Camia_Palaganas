# Hypotenuse Calculator

## Description
This python program calculates the hypotenuse of a triangle using the values of a and b.
The formula that will be used is the Pythagorean Theorem, which is: a^2 + b^2 = c^2

## How to Run
To open the program, you must download the file and open it in Pycharm. There, you will see the blocks of code labeled with comments.
After that, you must press the play button or shift+F10, and then you must input what the program asks you to and it will do the rest of the work for you.

## Input Needed
- side a
- side b

## Sample Output
- side a = 3
- side b = 4
- side c = 5
